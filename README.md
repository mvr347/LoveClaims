# LoveClaims

Продвинутая система захватов территорий с якорем-центром, арендой участков, флагами доступа и защитой от мародёрства.

## Описание

LoveClaims предоставляет полнофункциональную систему приватов для Minecraft серверов:

- **Якорь-ориентированные захваты** — захват территории на основе центральной точки (якоря)
- **Система租тов** — преобразование захвата в арендуемый участок с автоматическим продлением
- **Флаги доступа** — гибкое управление разрешениями (PvP, PvE, строительство, открытие контейнеров)
- **Защита от рейдов** — предотвращение строительства, майнинга и уничтожения блоков в захватах других игроков
- **Интеграция LoveCore** — использование единой валюты (монеты) для аренды и платежей
- **Расширение захватов** — постепенное увеличение границ захвата путём установки новых якорей

## Команды

| Команда | Алиасы | Описание | Пермишин |
|---|---|---|---|
| `/ac` | `claim`, `loveclaims`, `приват` | Главная команда управления приватами | - |
| `/rental` | `rent` | Управление арендой территорий | `loveclaims.rental` |
| `/loveclaimsadmin` | — | Административные команды | `loveclaims.admin` |

### Подкоманды `/ac`

- `/ac create` — создать новый захват в текущей позиции (там должен стоять якорь)
- `/ac delete` — удалить захват (смотреть на якорь)
- `/ac expand` — расширить захват в направлении взгляда
- `/ac info` — показать информацию о захвате
- `/ac flags` — управление флагами захвата (PvP, строительство, etc.)
- `/ac members` — добавить/удалить членов захвата
- `/ac leave` — выйти из захвата (для арендаторов)
- `/ac trust` — доверить захват другому игроку (передача прав)

### Подкоманды `/rental`

- `/rental list` — показать доступные для аренды участки
- `/rental rent <id>` — снять участок в аренду
- `/rental auto-renew` — включить/выключить автопродление
- `/rental info` — информация об активной аренде

### Подкоманды `/loveclaimsadmin`

- `/loveclaimsadmin reload` — перезагрузить конфигурацию
- `/loveclaimsadmin delete <player>` — удалить все захваты игрока
- `/loveclaimsadmin flag <flag> <true|false>` — управлять глобальными флагами
- `/loveclaimsadmin untrust <player>` — отозвать доверие у игрока

## Пермишины

| Пермишин | Описание | Default |
|---|---|---|
| `loveclaims.admin` | Доступ ко всем админ-командам | op |
| `loveclaims.bypass` | Игнорирование защиты всех приватов | op |
| `loveclaims.moderator` | Управление чужими приватами (модерация) | op |
| `loveclaims.rental` | Базовый доступ к аренде | true |
| `loveclaims.rental.admin` | Администрирование аренды | op |
| `loveclaims.rental.bypasslimit` | Обход лимита арендуемых участков | op |
| `loveclaims.bypass.expand` | Расширение захватов без ограничений по тиру | op |
| `loveclaims.bypass.flags` | Доступ ко всем флагам без открытия через квесты | op |

## Конфигурация

### Основные параметры захватов

```yaml
claiming:
  # Минимальное расстояние между якорями (в блоках)
  min-distance-between-anchors: 50
  
  # Базовый размер захвата
  default-radius: 100
  
  # Максимальный размер захвата
  max-radius: 500
  
  # Стоимость создания захвата (в монетах LoveCore)
  cost-to-create: 1000
  
  # Стоимость расширения захвата
  cost-to-expand: 500
```

### Флаги захватов

```yaml
flags:
  # PvP в захвате (true = разрешено)
  pvp: false
  
  # Строительство/разрушение блоков
  build: false
  
  # Открытие контейнеров
  containers: false
  
  # Посадка на животных
  mount-animals: false
  
  # Использование кроватей
  sleep: true
  
  # Активация редстоуна (рычаги, кнопки)
  redstone: false
```

### Система аренды

```yaml
rental:
  enabled: true
  
  # Длительность периода аренды (в днях)
  rental-period-days: 30
  
  # Базовая цена за период
  rental-price: 5000
  
  # Максимум активных арендованных участков на игрока
  max-active-rentals: 3
  
  # Автопродление (если включено и хватает денег)
  auto-renew: true
  
  # Штраф при просрочке платежа
  late-payment-fine: 500
```

### Защита территории

```yaml
protection:
  # Блокировать установку писков, ТНТ, кровать драконов
  block-explosions: true
  
  # Блокировать взлом при помощи эндермана/крипера
  block-enderman-grief: true
  
  # Запретить огню распространяться в захватах
  block-fire-spread: true
```

## Механика работы

### Создание захвата

1. Игрок ставит **якорь** (специальный блок) в желаемом центре территории
2. Использует `/ac create` находясь на якоре
3. Система создаёт круговой захват радиусом `default-radius`
4. Списываются `cost-to-create` монеты с инвентаря игрока

### Расширение захвата

1. Игрок ставит новый якорь на границе или дальше
2. Использует `/ac expand` смотря на новый якорь
3. Граница захвата расширяется до нового якоря
4. Списываются `cost-to-expand` монеты

### Аренда территории

1. Владелец захвата использует `/rental rent` чтобы предложить участок в аренду
2. Другой игрок использует `/rental list` и `/rental rent <id>` чтобы снять
3. Система автоматически списывает платёж каждый `rental-period-days`
4. При задолженности применяется `late-payment-fine`
5. Автопродление (если включено) автоматически продлевает аренду при каждом платёже

### Флаги и разрешения

- Владелец захвата может настроить 8+ флагов (PvP, строительство, контейнеры, etc.)
- Члены и арендаторы получают ограниченный доступ согласно флагам
- Администраторы с пермишином `loveclaims.bypass` игнорируют все ограничения

## Зависимости

### Обязательные

- **PlaceholderAPI** — интеграция плейсхолдеров
- **Paper 1.21** — базовый Minecraft сервер

### Мягкие зависимости

- **LoveCore** — система валюты (LoveEconomy) для оплаты захватов и аренды
- **CMI** — расширенная функциональность управления

## Интеграции

### PlaceholderAPI

| Плейсхолдер | Описание |
|---|---|
| `%loveclaims_owner%` | Владелец захвата в текущей позиции |
| `%loveclaims_members%` | Количество членов захвата |
| `%loveclaims_radius%` | Радиус захвата |
| `%loveclaims_claimed%` | Количество захватов игрока |
| `%loveclaims_rental_days%` | Дней осталось в аренде |

### LoveCore

Использует `LoveEconomy` для всех денежных транзакций (создание, расширение, аренда захватов).

mvn clean package

## Структура данных

- `claims` — таблица захватов (владелец, центр, радиус, флаги)
- `claim_members` — члены захватов (доступ, сроки истечения)
- `claim_rentals` — активные аренды (участок, арендатор, срок платежа)
- `claim_flags` — индивидуальные флаги для каждого захвата
- `claim_audit_log` — журнал изменений приватов (для модерации)

## Примечания

- Якорь должен быть установлен как блок специального типа (настраивается в конфиге)
- При удалении захвата все деньги, инвестированные в его расширение, не возвращаются
- Арендованные участки автоматически переходят в собственность после окончания срока, если владелец инертен
- Флаги наследуются от родительского захвата при создании подчинённого захвата
