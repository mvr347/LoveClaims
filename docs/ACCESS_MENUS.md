# Доступ и приглашения

В настройках доступа и правах участника используются головы. Текстуры четырёх
кнопок можно заменить в heads.yml: permission-build, permission-containers,
permission-interact, permission-manage. Подсказки ЛКМ/ПКМ берутся из lang.yml;
поддерживаются списки строк и строки с переносами.

«Добавить участника» открывает окно ввода ника. Кнопка «Отправить приглашение»
создаёт приглашение; права появляются после принятия игроком. Права приглашающего,
существование привата и лимиты проверяются при отправке. В пустом списке кнопка
находится в рабочей области; при наличии участников — перед «Назад», в слоте 51
для привата или 33 для аренды (номера с нуля).

Удаление привата, отказ от аренды и подтверждение её оплаты используют фон
ItemsAdder confirm_menu (также поддерживается confirm) и invisible-кнопки
itemsadder-voidcore:invisible. Поддерживается прямой API ItemsAdder без его
расширения PlaceholderAPI. Если ресурсы недоступны, остаются видимые кнопки
подтверждения и отмены в меню на 9 слотов.
